# Sample data

Everything in this folder is **fictional**. "Nova Drift" is a made-up show. The vendors, artists, shots and
AI-generation events were all written for this portfolio. None of it comes from a real studio, production or employer.

| File | Used by | Contents |
|---|---|---|
| `shots.csv` | Projects 1–3 | 26 shot records with mistakes added on purpose (bad names, invalid statuses, missing vendors, duplicate codes, etc.) |
| `vendors.csv` | Projects 1–3 | Vendor list with an active flag and a capacity limit |
| `genai_events.jsonl` | Project 4 | Event log from a pretend generative-AI tool (text, image, audio and video prompts, generations, downloads) |
